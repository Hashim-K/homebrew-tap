# Hashim-K Homebrew Tap

Homebrew formulas for Hashim-K projects and release binaries.

## Available Formulae

### Android Agent Lab (Linux)

Shared Android devices, scrcpy video, and visible agent cursors in a desktop app
and browser viewer. Supports x86_64 and ARM64 Linux desktops.

```bash
brew install hashim-k/tap/android-agent-lab
android-agent-lab
```

Requires system desktop libraries and ADB. See the
[installation guide](https://github.com/Hashim-K/android-agent-lab/blob/main/docs/desktop.md).

### UsageStat

Repository: [Hashim-K/usagestat](https://github.com/Hashim-K/usagestat)

```bash
brew install hashim-k/tap/usagestat
```

Release binaries are published from:

```text
https://github.com/Hashim-K/usagestat/releases
```
